
# Medicare - MERN Doctor Appointment Application

Medicare is a robust MERN (MongoDB, Express.js, React.js, Node.js) stack web application designed to streamline healthcare processes. This comprehensive platform facilitates doctor appointments, enables users to manage personal health blogs, provides access to medical facility information, incorporates a health-focused chatbot, and supports real-time communication between healthcare providers and patients.


## Unique Features:
Integrated Health Chatbot:

Real-time answers to health queries and symptom checks.
Personal Health Blogs:

Users can create, update, and delete health blogs with media.
Real-Time Communication:

Instant communication between doctors and patients using Socket.io.
Detailed Medical Facility Info:

Access services, contact details, and reviews for medical facilities.

## How to use the Project - 

1. Registration - 
Navigate to the registration page.
Fill in the required information (name, email, password, etc.).
Click on the "Register" button.

2. Login - 

After registration, or if already registered, navigate to the login page.
Enter the registered email and password.
Click on the "Login" button.

3. Home Page - 

Upon successful login, the user is redirected to the home page.
The home page displays general information, announcements, and available features.

4. View Available Doctors - 

Navigate to the "Doctors" section.
Browse through the list of available doctors.
Click on a specific doctor to view details.


5. Check Doctor's Availability and Book Appointment - 
On the doctor's profile page, view details such as their specialization, availability, etc.
Click on a time slot to view availability.

Book Appointment - 
Choose an available time slot.
Click on the "Book Now" button.
Confirm the selected time slot.

6. Appointment Notification - 

After booking, the user receives a confirmation message.
The appointment reque Doctor Approval/1. Rejectionst is sent to the selected doctor.

Doctor's Notification - 
The doctor receives a notification of the appointment request.
The doctor can choose to approve or reject the appointment.

7.  Doctor Approval/ Rejection - 

The user receives a notification indicating whether the appointment was approved or rejected.


8. Local Clinic Visit or Chatbot Interaction - 

If the appointment is approved, the user visits the specified local clinic at the scheduled time.
If the time doesn't match, the user is prompted to interact with the chatbot for assistance.

9.Blog Creation, Update, Delete, and Viewing - 

i) Create a Blog - 

Navigate to the "LoomHealth" section.
Create a new blog post with details about past health experiences.

ii) Update/Delete Blog - 

Users can update or delete their own blog posts.

iii) View All Patient Blogs - 

Navigate to the "Patient Blogs" section to view blogs shared by other patients.

10. Chat Application - 

Users can access the chat application to communicate with healthcare providers or other users in real-time.

11.  Logout - 

Click on the "Logout" button to securely log out of the Medicare application.
